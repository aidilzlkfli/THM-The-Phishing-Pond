# THM-The-Phishing-Pond
This training teaches users to detect phishing emails. It covers suspicious links, fake domains, macros, executive impersonation, and requests for personal data. Each scenario includes a reason why it is or isn't phishing.

# 📘 TryPhishMe Training – Phishing Pond Report

This document breaks down each level of the **TryPhishMe** interactive phishing training.  
Each scenario includes a description, why it is (or isn’t) phishing, and a placeholder for your screenshot.

---

## 🧠 Training Objectives

- Identify common phishing email characteristics  
- Recognize social engineering tactics  
- Develop critical thinking skills for email analysis  
- Practice real‑world phishing detection scenarios
